# PRODIGY_WD_04
A simple, responsive Weather App that fetches and displays current weather data for any city using the [OpenWeatherMap API](https://openweathermap.org/api).

---

## Features

- Search weather by city name
- Displays:
  - City name
  - Current temperature (°C)
  - Humidity percentage
  - Wind speed (km/h)
  - Weather condition icon (Clear, Clouds, Rain, Drizzle, Mist)
- Error handling for invalid city names
- Responsive and clean UI with smooth visuals

---

## Technologies Used

- HTML5
- CSS3 (Flexbox, gradients, and modern styling)
- JavaScript (ES6 + Fetch API)
- OpenWeatherMap API
